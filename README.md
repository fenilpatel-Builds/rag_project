# AI Platform - RAG Project

A modern AI application built with Next.js, React, Tailwind CSS, and TypeScript.

## 🚀 Features

- **Next.js App Router**: Optimized performance and server-side rendering.
- **Modern UI**: Designed with Tailwind CSS and responsive layouts.
- **TypeScript**: End-to-end type safety.

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Running Locally

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
